# Проверка проекта

## Выполнено в среде подготовки

- `tests/smoke.php`: 25 проверок успешно исполнены через PHP WebAssembly и PDO SQLite.
- CLI-установщик создал базу, помещения и администратора.
- PHP сформировал все шесть страниц без предупреждений и ошибок; кабинеты проверены с тестовыми заявками трёх статусов.

- Синтаксис всех PHP-файлов проверен грамматикой Tree-sitter PHP: ошибок разбора нет. Это не заменяет `php -l` и исполнение приложения.
- Синтаксис JavaScript: `node --check public/assets/app.js`.
- Исполнение SQL-схемы SQLite в памяти.
- Проверка внешних ключей пользователей, помещений и заявок.
- Проверка уникального логина без учёта регистра.
- Проверка уникального отзыва на заявку, границ оценки, способов оплаты и статусов.
- Проверка XML всех SVG-иллюстраций и ER-диаграммы.
- Обзор запросов: параметры передаются через PDO prepare/execute; роль и user_id определяются сервером.

Обычный PHP и MySQL не установлены в среде подготовки. Серверная логика выполнена в дополнительной среде PHP WebAssembly с SQLite; это не заменяет запуск на целевом PHP/MySQL-сервере. Визуальная браузерная проверка не выполнялась.

## Перед демонстрацией

После настройки PHP выполните из корня проекта:

```bash
php -l public/index.php
php -l app/bootstrap.php
php -l app/Database.php
php -l app/Auth.php
php -l app/Booking.php
php -l app/views.php
php -l database/setup.php
php tests/smoke.php
php database/setup.php
php -S 127.0.0.1:8000 -t public
```

## Контрольные сценарии

| Действие | Ожидаемый результат |
|---|---|
| Открыть главную без входа | Видны три помещения, ссылки и кнопки |
| Отправить регистрацию с пустыми полями | Отправка блокируется браузером; сервер тоже отклоняет некорректные данные |
| Логин короче 6 символов или кириллицей | Ошибка возле логина |
| Пароль короче 8 символов | Ошибка возле пароля |
| ФИО латиницей, неправильные email или телефон | Ошибки соответствующих полей |
| Корректная регистрация | Аккаунт сохранён, переход ко входу |
| Повторить логин с другим регистром | Уникальность не нарушается, сообщение об ошибке |
| Ввести неверный пароль | Сообщение об ошибке без входа |
| Сделать 8 неверных попыток с одним логином/IP | Следующая попытка ограничивается на 15 минут |
| Войти зарегистрированным пользователем | Личный кабинет |
| Отправить заявку на будущую дату | Запись в БД, статус «Новая», карточка в кабинете |
| Подставить несуществующее помещение или способ оплаты | Сервер отклоняет заявку |
| Подставить дату в прошлом | Ошибка даты |
| Обновить страницу после успешной отправки | Дубликат не создаётся: применяется POST/Redirect/GET |
| Второй пользователь открывает кабинет | Не видит заявки первого пользователя |
| Пользователь открывает page=admin | HTTP 403 |
| Гость открывает личный кабинет | Переход ко входу |
| Администратор входит с Conf2027 / Demo77 | Панель со всеми заявками |
| Поиск по имени, логину, помещению и фильтр по статусу | Отображаются соответствующие заявки |
| Назначить мероприятие | Статус меняется у администратора и пользователя |
| Завершить назначенное мероприятие | Пользователю доступна форма отзыва |
| Отправить отзыв до завершения, в том числе вручную | Сервер отклоняет запрос |
| Подставить чужой booking_id при отзыве | Сервер отклоняет запрос |
| Отправить отзыв с оценкой 1–5 и 10–2000 символами | Отзыв виден пользователю и администратору |
| Повторно отправить отзыв | Второй отзыв не сохраняется |
| Отправить POST без корректного CSRF-токена | HTTP 419, изменения не выполняются |
| Вставить HTML в отзыв | Отображается текстом, не исполняется |
| Выйти и открыть закрытую страницу | Нужна повторная авторизация |
| Проверить 390×844 и 1440×1024 | Нет горизонтального переполнения, все элементы доступны |
| Навигация Tab / Enter и мобильное меню | Видимый фокус, рабочие ссылки и формы |
| Отключить JavaScript | Основные формы и серверные проверки продолжают работать |

Мобильная навигация раскрывается JavaScript; без него страницы входа/кабинета остаются доступны по прямым ссылкам и кнопкам основного содержимого. Для реальной публикации завершите эти сценарии на целевом PHP/MySQL-сервере.
