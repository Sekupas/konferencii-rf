# Дизайн и соответствие заданию

Светлый интерфейс с тёмным текстом, зелёным акцентом и спокойными геометрическими иллюстрациями помещений. Изображения в SVG масштабируются без пикселизации и не загружаются из внешних сервисов.

| Элемент | Значение |
|---|---|
| Основной текст | `#142e35` |
| Второстепенный текст | `#66767b` |
| Акцент и кнопки | `#00695e` |
| Декоративный лаймовый | `#d7ef87` |
| Фон | `#f7f9f7` |
| Поверхности | `#ffffff` |
| Шрифт | Arial / Segoe UI / sans-serif |
| Радиусы | 9–10 px для полей, 18–22 px для карточек |
| Контент | До 1240 px, мобильные поля 18 px |
| Кнопки | Высота 44–52 px |

Компоненты: логотип, шапка, мобильное меню, кнопки, поля с подсказками и ошибками, переключатель видимости пароля, выпадающий список помещений, карточки способов оплаты, сообщения об успешных действиях, фильтры статусов, поиск, счётчики, карточка заявки и форма отзыва.

Адаптивные правила предусмотрены для 600, 850 и 1100 px. На ширине 390 px формы и помещения занимают одну колонку, счётчики — две; меню раскрывается кнопкой. Страницы прокручиваются по высоте и не обрезаются рамкой 844 px. Проверка в настоящем браузере на 390×844 и 1440×1024 указана в плане приёмки и в текущей среде не выполнена.

Доступность: подписи полей, клавиатурный фокус, ссылка пропуска навигации, aria-атрибуты меню и ошибок, сообщения role=alert/status, настройка prefers-reduced-motion. Ошибки дополнительно проверяются PHP, поэтому отключение JavaScript не обходит бизнес-правила.

| Требование | Реализация |
|---|---|
| Приветствие, помещения, преимущества, навигация | `page=home` |
| Авторизация и ссылка на регистрацию | `page=login` |
| Обязательные поля и уникальный логин | `page=register`, `Auth.php` |
| Выбор помещения, даты, времени и оплаты | `page=booking`, `Booking.php` |
| Просмотр своих заявок | `page=dashboard`, запрос с user_id из сессии |
| Отзыв после завершения | `Booking::review`, серверная проверка |
| Администратор Conf2027 / Demo77 | Создаётся CLI-установщиком |
| Все заявки, поиск, фильтры, статусы | `page=admin` |
| SQL-связи и диаграмма | `database/`, `docs/ER-diagram.svg` |
| ООП | Классы Database, Auth, Booking |
| Микроанимации | CSS для кнопок и карточек, reduced-motion |
| Figma и Gimp | Заменены кодом по прямому запросу пользователя |

ER-диаграмма построена по поставляемой схеме программно. Экспорт из графического интерфейса СУБД не выполнялся.
