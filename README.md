# Конференции.РФ

В репозитории две версии сайта:

- **GitHub Pages** — `pages/`: HTML, CSS и JavaScript. Регистрация, вход, заявки, статусы, фильтры и отзывы работают в демонстрационном режиме. Данные сохраняются только в localStorage текущего браузера. Общего сервера, реальных бронирований и платежей нет.
- **PHP + SQL** — `app/`, `public/`, `database/`. Инструкция: [docs/PHP_SETUP.md](docs/PHP_SETUP.md).

## Публикация на GitHub Pages

1. Откройте **Settings → Pages**.
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. Откройте **Actions → Publish GitHub Pages → Run workflow** и запустите workflow для `main`.
4. После успешного выполнения: https://sekupas.github.io/konferencii-rf/

Дальнейшие изменения в `pages/` публикуются автоматически. Сайт должен обслуживаться по HTTPS: для демонстрационных паролей используется Web Crypto API.

## Как проверить

1. Создайте демоаккаунт с вымышленными данными и отдельным учебным паролем.
2. Выберите помещение, будущую дату и время по Москве и создайте заявку.
3. Выйдите и войдите как **Conf2027 / Demo77** в том же браузере.
4. Дважды смените статус: «Новая» → «Мероприятие назначено» → «Завершено».
5. Войдите своим демоаккаунтом и оставьте отзыв.
6. Кнопка «Сбросить демоданные» удаляет локальные аккаунты, заявки и отзывы.

Демоадминистратор видит только записи в текущем браузере. Клиентские проверки и локальные аккаунты не являются серверной авторизацией.

## Проверки Pages

JavaScript прошёл `node --check`; проверены экранирование HTML, демонстрационные данные помещений, чтение хранилища, выбор роли сеанса, PBKDF2, преобразование московского времени и ссылки на ресурсы. Визуальная проверка браузером в текущем окружении недоступна.
